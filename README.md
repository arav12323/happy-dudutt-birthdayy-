# Happy Birthday Indah 💗

Versi ini sudah dirapikan khusus untuk GitHub Pages.

## Cara upload
Upload **semua isi folder ini** ke root repository `happy-dudutt-birthdayy-`.

Struktur yang benar:

```text
index.html
style.css
script.js
assets/
  images/
    photo-01.webp
    photo-02.webp
    ...
    malang-new.webp
.nojekyll
README.md
```

Lalu buka **Settings → Pages → Deploy from a branch → main → /(root)**.

Backsound sengaja dihapus dari website. Tambahkan lagu manual setelah screen-record atau lewat Instagram/CapCut.
